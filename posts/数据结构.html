B维正交范围

对于一个维的点,满足,称所有这样的点组成的集合为一个维正交范围.

一维正交范围就是区间,二维正交范围是矩形,三维正交范围是立方体.

另外,如果有若干个是自动满足的(所有点都满足),那么我们称它为无用限制,如果一个维正交范围有个有用限制,称它为的.

二维分块

我们现在有一个需要维护的的平面,我们现在对其进行分块:

  1. 将平面分成个的块,以块为单位做二维前缀和.

  2. 每个块内部分成个的块,在块内部以块为单位做二维前缀和.

  3. 将整个平面横着分别分成一个个的块.(竖着也要分成一个个的块,是类似的,略去)

  4. 每个块内部分成个个块,在块内部以块为单位做二位前缀和.

注意到修改一个点的时候,需要更新三次二位前缀和,每次复杂度.同时注意到空间复杂度是的.

查询显然是分四种情况讨论:块都可以快速求得答案,接下来只需要做一下散块就行.

那散块怎么做呢?我们考虑一个特殊情况:修改点的纵坐标以及横坐标两两不同,或至少一个坐标只对应个点.

如果查询的时候,也仍然是满足查询的一个对应个,我们就可以枚举一个点被哪些查询查到了散块,显然只有可能有个查询,记录一下即可.这样就做到了单点改,查询.

如果我们一开始不做二维前缀和,就可以实现单点改,那这种情况下如何实现求和呢?首先还是可以求出整块的和.

横着和竖着的散块相同,只讨论横着的.由于横着的散块高度,我们就可以在每次查询的时候用的复杂度枚举一遍横纵坐标在这个区间的点然后暴力判断即可,也可以求散块.

这个问题解决了,我们再回到一开始:为啥要对分块?

一方面,题目中的是给定的.另一方面,我们注意到我们需要维护一个和有关的东西,而如果没有,或者说的时候,这个东西是好维护的:一般的区间最大子段和其实暗含了的条件.考虑到这一点,对分块就合情合理了.换句话说,分块其实有两种用途:一种是平衡暴力的复杂度:它可以让一些和块长有关的暴力复杂度降低.另一种用途是保证某个东西的合法性.

因为一开始这样会使得运算过程中有可能出现比还要小的数字,最底层的有可能覆盖掉上面的.

ll mabs(ll x){

void pushup(int cnt){
    tr[cnt].l=tr[cnt].r=tr[cnt].x;
    tr[cnt].d=tr[cnt].u=tr[cnt].y;
    tr[cnt].siz=1;
    if(tr[cnt].son[0]){
        tr[cnt].l=std::min(tr[cnt].l,tr[tr[cnt].son[0]].l);
        tr[cnt].r=std::max(tr[cnt].r,tr[tr[cnt].son[0]].r);
        tr[cnt].d=std::min(tr[cnt].d,tr[tr[cnt].son[0]].d);
        tr[cnt].u=std::max(tr[cnt].u,tr[tr[cnt].son[0]].u);
        tr[cnt].siz+=tr[tr[cnt].son[0]].siz;
    }
    if(tr[cnt].son[1]){
        tr[cnt].l=std::min(tr[cnt].l,tr[tr[cnt].son[1]].l);
        tr[cnt].r=std::max(tr[cnt].r,tr[tr[cnt].son[1]].r);
        tr[cnt].d=std::min(tr[cnt].d,tr[tr[cnt].son[1]].d);
        tr[cnt].u=std::max(tr[cnt].u,tr[tr[cnt].son[1]].u);
        tr[cnt].siz+=tr[tr[cnt].son[1]].siz;
    }
    return ;
}
inline ll dispp(int pa,int pb){
    return 1ll*mabs(tr[pa].x-tr[pb].x)+1ll*mabs(tr[pa].y-tr[pb].y);
}
inline ll dispm(int po,int mat){
    if(!mat)return 320051113;
    ll d=0;
    if(tr[po].x<tr[mat].l)d+=tr[mat].l-tr[po].x;
    if(tr[po].x>tr[mat].r)d+=tr[po].x-tr[mat].r;
    if(tr[po].y<tr[mat].d)d+=tr[mat].d-tr[po].y;
    if(tr[po].y>tr[mat].u)d+=tr[po].y-tr[mat].u;
    return d;
}
bool get_var(int l,int r){
    double avx=0,avy=0;
    for(int i=l;i<=r;++i){
        avx+=p[i].x;avy+=p[i].y;
    }
    avx/=(r-l+1);avy/=(r-l+1);
    double varx=0,vary=0;
    for(int i=l;i<=r;++i){
        varx+=1ll*(avx-p[i].x)*(avx-p[i].x);
        vary+=1ll*(avy-p[i].y)*(avy-p[i].y);
    }
    return varx<vary;
}
int build(int l,int r){
    if(l>r)return 0;
    int mid=(l+r)>>1;
    int cnt=cur[mid];
    tr[cnt].f=get_var(l,r);
    if(tr[cnt].f)std::nth_element(p+l,p+mid,p+r+1,cmpy);
    else std::nth_element(p+l,p+mid,p+r+1,cmpx);
    tr[cnt].x=p[mid].x;tr[cnt].y=p[mid].y;tr[cnt].siz=1;
    tr[cnt].son[0]=build(l,mid-1);
    tr[cnt].son[1]=build(mid+1,r);
    pushup(cnt);
    return cnt;
}

但是可以优化,我们设表示当前众数出现次数,注意到我们判断一个数字在区间中出现次数是否大于可以判断(处理出这个数所有的出现位置),而如果遇到两个数需要对冲,显然增加总次数也不会超过,因此做到.

不删除莫队也能做.

当然,如果只要求区间众数的出现次数,可以直接莫队.

Example2(CodeChef Chef and Churu)

首先发现函数是不会被修改的,因此考虑对函数分块,对于那些散着的函数肯定可以用一个查询区间和,单点修改的进行根号平衡.

而怎么快速处理整块呢?发现函数可差分,差分后就可以算出每一个位置对这个块内的总贡献,这样就可以更新了.

莫队,发现有次查询,次移动,于是根号平衡.

事实上考虑可能的答案只有种,用值域分块就可以平衡复杂度.
